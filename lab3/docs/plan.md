### 3. Плагин: сохранить оценку в базу

Сейчас звёзды можно нажимать, но значение не уходит в базу. Действия:

1. `Data` → `Data types` → `Отметка выполнения` → `Create a new field`:
   имя `rating`, тип `number`.
2. В workflow `Создать отметку` в действии `Create a new Отметка
   выполнения` → `+ Set another field` → `rating = <звёзды>'s value`.
3. В карточке отметки вывести `Current rating` рядом со звёздами.
4. Скриншот вставленной оценки в базе (`12-plugin-rating.png`).

### 4. Название и автор плагина

Открыть `Plugins` → выписать название плагина и автора — они нужны в
разделе 6.1 отчёта и на защите. Без них раздел не защитить.
