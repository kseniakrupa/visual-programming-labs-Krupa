## Часть 4. Data и Workflows

### 4.1. Data Type «Habit»

`Data` → `Data types` → `+ New type` → `Habit`. Поля (7 штук, все типы разные):

| Поле | Тип | Обязательное | Смысл |
|---|---|---|---|
| `Title` | text | да | название привычки |
| `Start date` | date | да | с какой даты ведём |
| `Periodicity` | Option Set `Periodicity` | да | как часто повторять |
| `Status` | Option Set `HabitStatus` | да | текущее состояние |
| `Notifications on` | yes/no | нет | нужны ли напоминания |
| `Target per week` | number | нет | цель, раз в неделю |
| `Note` | HabitNote (ссылка) | нет | заметка к привычке |

Option Set `Periodicity` (три варианта): `Daily` — «Ежедневно»,
`Weekly` — «Еженедельно», `Monthly` — «Ежемесячно».
Option Set `HabitStatus` (четыре варианта): `Active` — «Активна»,
`Paused` — «Приостановлена», `Done` — «Завершена», `Archived` — «В архиве».

Второй Data Type — `HabitNote` (нужен, чтобы показать поле-ссылку и
разные типы в одной сущности):

| Поле | Тип | Смысл |
|---|---|---|
| `Text` | text | текст заметки |
| `Created at` | date | когда добавлена |
| `Important` | yes/no | закрепить |
| `Weight` | number | приоритет, 1–10 |
| `Habit` | Habit (ссылка) | к какой привычке относится |
| `Link` | link (website) | внешняя ссылка-источник |

Записи: 3 привычки через `App Data` (например «Пить 2 литра воды»,
«Чтение перед сном», «Пробежка по выходным») и 2 заметки к ним.

Скриншоты: `screenshots/06-data-type.png` (поля и типы),
`screenshots/07-data-records.png` (записи в App Data).

### 4.2. CRUD на новой странице

Создать страницу `habits` (`Design` → `+ Add a new page`, имя `habits`,
заголовок «Мои привычки: управление»). UI можно сгенерировать AI-агентом
промптом из отчёта, затем поправить вручную.

Четыре отдельных workflow:

| # | Workflow | Событие | Действия |
|---|---|---|---|
| 1 | `Create Habit` | кнопка «Создать привычку» | `Create a new Habit` (Title, Start date, Periodicity, Status = Active) → `Reset inputs` → `Show alert` |
| 2 | `Read Habits` | `Page is loaded` / `Do every 5 seconds` | `Display list` в RepeatingGroup, источник `Search for Habit` (сортировка по `Start date`, descending) |
| 3 | `Update Habit` | кнопка «Сохранить» внутри карточки | `Make changes to Current cell's Habit` (Title = input, Status = dropdown) → `Show alert` |
| 4 | `Delete Habit` | кнопка «Удалить» внутри карточки | `Delete Current cell's Habit` → `Show alert` |

Проверка обязательно в `Preview`: создать привычку, переименовать,
удалить и снять скриншоты.

Скриншоты: `screenshots/08-workflow-read.png`,
`screenshots/09-workflow-create.png`, `screenshots/10-workflow-delete.png`
(дополнительно можно `09a`/`09b` — update).

## Часть 5. Ачивка

**Ачивка 1 — API Connector (CRUD).** Публичный API без ключа и регистрации:
`https://dummyjson.com/todos` — сущность «задача», по смыслу совпадает с
привычкой, поэтому данные из внешнего API можно показать в том же
приложении, в блоке «Задачи из внешнего API».

| Метод | Адрес | Что делает |
|---|---|---|
| GET | `/todos` | список задач |
| GET | `/todos/1` | одна задача |
| POST | `/todos/add` | создать |
| PUT | `/todos/1` | изменить |
| DELETE | `/todos/1` | удалить |

Настройка: `Plugins` → `API Connector` → `+ Add another API` → имя `DummyJSON
Todo`, `Authentication: None`, метод `GET`, `Use as: Action`, `Data type:
JSON`, затем `Initialize call` и вручную описать поля `id`, `todo`,
`completed`, `userId`. Остальные методы — кнопкой `+ Add another call`.

Демонстрация через UI: RepeatingGroup с источником `Get todos`'s `todos`,
кнопки «Добавить задачу», «Отметить выполненной», «Удалить».
Документация — `lab3/docs/api.md`.

Скриншоты: `screenshots/11-api-*.png`.
