# Экспорт workspace

Xano выгружает workspace в ZIP через **Settings → Export** (или
**Workspace → Export** в зависимости от версии интерфейса).

1. Открыть workspace `lab8-krupa-api`.
2. Settings → Export → скачать архив.
3. Переименовать в `lab8-krupa.zip` и положить в эту папку.
4. Закоммитить: `git add lab8/exports/lab8-krupa.zip && git commit -m "lab8: add workspace export"`.

Проверка перед коммитом: в архиве есть `db/` (таблицы с данными) и
`api/` (эндпоинты), размер — единицы мегабайт. Архивы с секретами
(токены, ключи окружения) не коммитятся.

Дополнительно в папке лежит `openapi.yaml` — контракт API, по которому
собирались таблицы и эндпоинты. Он не заменяет экспорт Xano, но фиксирует
схему в git и позволяет проверить расхождения.
